# Практическое задание 3Б — Справочник пользователей

Веб-приложение на HTML, CSS и JavaScript без библиотек. Данные загружаются с публичного тестового REST API [JSONPlaceholder](https://jsonplaceholder.typicode.com/).

## Запуск

Откройте `index.html` через Live Server в VS Code. Альтернативный запуск из папки проекта:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`. Для GET-запросов нужен доступ к интернету. База данных, серверная часть и `localStorage` не используются.

## Реализованные возможности

- Кнопка «Загрузить пользователей»: `GET /users`, вывод имени, email и города каждого из десяти пользователей.
- Поле «Поиск по имени»: фильтрация загруженного массива с помощью `filter()` без дополнительных HTTP-запросов, без учёта регистра.
- Кнопка «Показать публикации»: `GET /posts?userId=ID` для выбранного пользователя и вывод первых трёх публикаций.
- Индикатор «Загрузка...», блокировка кнопок при запросах, проверка `response.ok`, обработка ошибок через `try/catch/finally`.
- Отображение полученных HTTP-кодов и сообщений об ошибках, возможность повторного запроса.
- Динамическое создание элементов через DOM с помощью `createElement()`, `textContent` и `appendChild()`; страница не перезагружается.

## Проверка

Сценарии для демонстрации:

1. Нажать «Загрузить пользователей» — должны появиться 10 пользователей.
2. Ввести `Leanne` — должна остаться соответствующая запись; ввести отсутствующее имя — сообщение «Пользователи не найдены».
3. Нажать «Показать публикации» у любого пользователя — должны появиться заголовки и тексты трёх публикаций.
4. Временно изменить `/users` на `/userz` в `USERS_URL` — должна появиться ошибка HTTP 404. Вернуть правильный адрес и повторить загрузку.
5. При ошибке HTTP или сети кнопки снова становятся доступными; для сетевого сбоя без ответа сервера код не показывается.
